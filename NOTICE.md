# Notice and Attribution

## Inspiration

Novice Skill Builder was inspired by the public project [JimLiu/baoyu-skills](https://github.com/JimLiu/baoyu-skills), created by Baoyu.

The baoyu-skills project demonstrates many strong patterns for practical AI skills: clear triggering descriptions, progressive disclosure through references, script-backed execution for fragile operations, configuration layers, user confirmation points, and explicit output contracts.

## Boundary

This repository is an independent project.

It is not:

- an official baoyu-skills project
- a mirror of baoyu-skills
- a fork or redistribution of baoyu-skills
- a package containing baoyu-skills source code

This repository intentionally excludes:

- the downloaded baoyu-skills source tree
- original baoyu skill files
- screenshots and image assets from baoyu-skills
- long excerpts or full copies of baoyu-skills documentation
- platform publishing scripts from baoyu-skills

## What This Repository Contains

This repository contains an independently written Codex skill that helps novice users turn plain-language workflow needs into skill drafts.

It uses general design lessons learned from studying public skill patterns, but the released files are written for this project and are meant to be used as a new novice-guided workflow.
